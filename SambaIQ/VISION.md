# 🏆 SambaIQ - "Duolingo för Fotboll"
## AI-driven fotbollsscenarier för barn 7-16 år

### 🎯 CORE CONCEPT:
- AI-driven "Duolingo för fotboll" med interaktiv fotbollsplan
- SVFF/UEFA/global akademi-data som grund
- Ålder 7-16 med adaptiv svårighetsgrad

### 🎮 GAMEPLAY:
- AI genererar scenarier → Plan visualiserar → Barn interagerar → AI ger pedagogisk feedback
- Frågetyper: positionering, bollhantering, försvar, speluppbyggnad

### 🏆 PROGRESSION:
- XP-system med säsonger (100 XP = ny säsong)
- Streak-bonusar för daglig träning  
- Personlig avatar som speglas på planen

### 🎨 UI/UX DESIGN:
**FC 25-26 INSPIRERAD DESIGN:**
- ✅ Modern glassmorphism → Genomskinliga kort med blur-effekter
- ✅ Gradient bakgrunder → Fotbollsgröna till blå övergångar
- ✅ Sleek animationer → Smooth transitions, hover-effekter
- ✅ Premium känsla → Polerad, professionell design
- ✅ Dark/light themes → Anpassar sig efter tid på dagen

**SNYGGA CITAT SOM FEEDBACK:**
- ✅ Inspirerande → "Som Messi sa: 'Det handlar om att fatta rätt beslut'"
- ✅ Pedagogiska → "Guardiola: 'Fotboll spelas med hjärnan först'"
- ✅ Motiverande → "Zlatan: 'Bra spelare vågar ta risker'"
- ✅ Åldersanpassade → Enklare citat för yngre, djupare för äldre

**VISUELL STIL:**
- 🎨 FC-färger → Grönt gräs, vit linjer, gul/röd kort-färger
- ⚡ Smooth animationer → Spelare glider över planen
- 🏆 Premium ikoner → Kristallklara, vektorbaserade

### 📱 TEKNISK STACK:
- **Frontend:** React Native + Expo SDK 49
- **Backend:** Supabase (PostgreSQL + Edge Functions)
- **AI:** OpenAI/Claude via Supabase Edge Functions
- **Auth:** Supabase Auth
- **Storage:** Supabase Storage
- **Realtime:** Supabase Realtime för vänner/leaderboards
- **Plattform:** iOS-först, sedan Android

### 🔔 ENGAGEMENT FEATURES:
**PUSH NOTISER:**
- ✅ Streak påminnelser → "Din 7-dagars streak väntar! ⚽"
- ✅ Nya säsonger → "Säsong 3 är nu upplåst! 🏆"
- ✅ Motiverande → "Dags för dagens fotbollsträning! 🔥"
- ✅ Smart timing → Skickas när barnet brukar spela

**VÄNNER SYSTEM:**
- ✅ Lägg till vänner → Via kod eller namn
- ✅ Jämför progress → "Du är 50 XP före Marcus!"
- ✅ Utmaningar → "Vem kan klara flest frågor idag?"
- ✅ Dela achievements → "Jag klarade Säsong 2! 🎉"
- ✅ Leaderboards → Vecko/månads-topplista

### 🤖 AI INNEHÅLL:
- ✅ Oändligt med säsonger - AI bygger hela tiden nya frågor
- ✅ Dynamisk progression → Appen växer med barnet
- ✅ Unik upplevelse → Varje barn får olika frågor/scenarier
- ✅ Evigt engagemang → Ingen "slutar spela för att det är slut"

### 🎯 MÅLGRUPPER:
- **7-9 år:** Mini fotboll (7v7 plan) - Grundläggande koncept
- **10-12 år:** Riktig fotboll (9v9 plan) - Taktiska grunder  
- **13-16 år:** Akademi nivå (11v11 plan) - Avancerad taktik

### 🚀 MVP FOKUS:
**"Första 5 minuterna måste vara MAGISKA!"**
- Instant engagement utan tråkiga tutorials
- Omedelbar framgång - första scenario måste vara vinbart
- Visuell wow-faktor - vacker fotbollsplan
- Personlig koppling - "Detta är MIN fotbollsresa"
