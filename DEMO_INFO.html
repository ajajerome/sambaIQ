📱 För att testa SambaIQ:

Option 1: Lokalt på din dator

1. Klona projektet från GitHub:

git clone https://github.com/ajajerome/sambaiq.git
cd sambaiq && npm install
npm run web

Option 2: Expo Go (Mobil)

1. Ladda ner "Expo Go" från App Store/Google Play

2. Kör: npx expo start --tunnel

3. Scanna QR-koden

Option 3: EAS Build (Production)

Ready för iOS TestFlight & Android deployment!

eas build --platform ios
