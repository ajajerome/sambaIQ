# 🚀 SambaIQ Quick Start Guide

## ⚡ Snabbstart för Utveckling

### 1. **Starta Development Server**
```bash
cd SambaIQ
npm start
```

### 2. **Testa På Enhet**
- Scanna QR-kod med Expo Go app
- Eller tryck 'i' för iOS simulator
- Eller tryck 'w' för web (begränsad funktionalitet)

### 3. **Snabba Iterationer**
- JavaScript-ändringar = Hot reload (sekunder)
- Native ändringar = Rebuild (minuter)
- Crash? Tryck 'r' för restart

## 🔧 Development Commands:

### **Starta Appen:**
```bash
npm start              # Standard Expo server
npm run ios           # iOS simulator
npm run android       # Android emulator
npm run web           # Web browser
```

### **Debugging:**
```bash
npx expo r -c         # Clear cache och restart
npx expo install --fix # Fix dependency versions
```

### **Build & Deploy:**
```bash
eas build --platform ios --profile preview
eas submit --platform ios --latest
```
